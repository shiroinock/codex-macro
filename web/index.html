C100 COMPANIONWEB FLASHER · 実験版

KEYCHRON C100 8K

キーに、新しい役割を。

元のファームウェアを手元に保存してから、
タスクとアクションを操作する専用コントローラーへ。

まずは macOS の Chrome 向け。実機でバックアップ保存・書き込み・読み戻し照合・再起動後の Companion 動作を確認済みです。初回バックアップから通常ファームウェアへの復元・文字入力と、専用ファームウェアへの再導入も確認済みです。
バックアップはこの端末で処理し、サーバーへ送信しません。

01

C100 を接続する

Companion のデーモンと Keychron Launcher を停止し、別のキーボードを用意します。

  1. USB を抜きます。
  2. 左上の K00 を押したまま挿し直します。
  3. 約 3 秒で離し、下のボタンから DFU デバイスを選びます。

DFU の USB ID は他の機種でも共通です。本体の機種も必ず確認してください。

未接続

02

元の状態を保存する

現在のフラッシュ全体（256 KiB）を読み出します。すでに専用ファームウェアなら、その状態が保存されます。保存したファイルを選び直し、内容が一致することを確認します。

バックアップを保存 ↓

接続すると読み出せます。

03

専用ファームウェアを書き込む

配布イメージを確認中…

処理中は USB を抜かず、ページを閉じないでください。読み戻しが一致するまで再起動しません。

バックアップから復元

この本体から保存した 256 KiB のファイルを選びます。復元前にも現在の状態のバックアップを保存・照合してください。
